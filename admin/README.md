# Локальная админ-панель WhySpent

Панель предназначена только для владельца WhySpent. Она не публикуется в
интернете и не является частью пользовательского приложения.

## Что умеет

- искать пользователей и смотреть их доступ, токен, платежи и историю ручных действий;
- выдавать или продлевать платный, реферальный и пробный доступ;
- отзывать доступ и активные Shortcut-токены;
- смотреть ключевые показатели: пользователей, активность, подписки и Stars;
- отправлять Telegram-рассылки по сегментам;
- сначала присылать тестовое сообщение владельцу, затем ставить рассылку в очередь;
- вести журнал всех ручных действий и результатов доставки.

## Однократная настройка

В файле `.env.admin` добавьте строку с длинным уникальным паролем:

```dotenv
ADMIN_PASSWORD=придумайте-длинный-уникальный-пароль
```

`SUPABASE_SECRET_KEY` уже находится в этом локальном файле. Не
отправляйте `.env.admin`, его содержимое или пароль другим людям.

## Запуск

Откройте два окна терминала в корне репозитория.

В первом:

```bash
bun run admin:server
```

Во втором:

```bash
bun run admin:dev
```

Затем откройте [http://127.0.0.1:5174](http://127.0.0.1:5174).

Сервер панели слушает только `127.0.0.1`. Ключ Supabase остаётся внутри него:
браузер получает лишь защищённую локальную сессию.

## Рассылки

Для защиты от случайной отправки у каждой рассылки обязательный порядок:

1. Выбрать сегмент и написать текст.
2. Нажать «Отправить тест себе».
3. Проверить Telegram-сообщение.
4. Подтвердить отправку.

После подтверждения сервер панели сам обрабатывает очередь небольшими
порциями. Оставьте первое окно терминала открытым, пока статус рассылки не
станет «Отправлено» или «С ошибками». Ошибки доставки не повторяются бесконечно:
для временных проблем предусмотрено не более трёх попыток.
